# Manufacturing Cost Analysis Dashboard — FY 2024

## Overview
A multi-page cost accounting dashboard built in Power BI, backed by a 
structured Excel data model covering product costing, budget variance, 
and inventory/COGS analysis.

## Tools Used
- Microsoft Power BI Desktop
- Microsoft Excel
- DAX (Data Analysis Expressions)

## Key Features
- Unit cost breakdown by product (raw materials, labour, overhead)
- Gross margin % by product
- Budget vs Actual cost variance with ▲ Favourable / ▼ Adverse indicators
- Monthly COGS vs Revenue trend (Jan–Dec)
- KPI cards: Total COGS, Gross Profit, Average Gross Margin, Budget Variance

## Key Metrics (FY 2024)
- Total COGS (YTD): ₦589K
- Total Revenue: ₦860K
- Gross Profit: ₦271K
- Average Gross Margin: 31.55%
- Budget Variance: -9.98% (over budget)
